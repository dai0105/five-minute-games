HOW I MAKE

5分ゲームの制作

アイデアから公開まで、ひとつずつ。

「5分ゲーム」は、 ちょっとした時間にすぐ遊べる 小さなWebゲームシリーズです。

ゲームのアイデアを考えるところから、 ルール設計、実装、スマホ対応、 そしてWebへの公開まで取り組んでいます。

01

💡 IDEA

5分で遊べる ゲームのアイデアを考える。

02

🎮 GAME DESIGN

ルールやスコア、 「もう1回」と思える仕組みを考える。

03

💻 DEVELOPMENT

Python / Django / HTML / CSS / JavaScriptで実装する。

04

📱 TEST

PCとスマホで実際に遊びながら、 操作や表示を調整する。

05

🚀 RELEASE

GitHubで管理して、 RenderからWebへ公開する。

TECH STACK

使用技術

5分ゲームを支えている技術。

🐍

Python / Django

ゲームの処理や Webアプリの土台を構築。

🌐

HTML / CSS

ゲーム画面や、 スマホでも遊びやすい レイアウトを制作。

⚡

JavaScript

ボタン操作やアニメーション、 ゲーム中の動きを実装。

🗂️

Git / GitHub

ソースコードと 制作過程の変更を管理。

🚀

Render

完成したWebゲームを オンラインで公開。

VALUES

大切にしていること

小さくても、ちゃんと遊びたくなるゲームを。

⏱️

5分で遊べる

長い説明を読まなくても、 すぐに始められて、 短い時間でひと区切り。

🎮

毎回ちがう遊び

経営、運、計算、反射神経。 同じシリーズでも、 毎回ちがうゲーム体験を目指します。

🔁

もう1回遊びたくなる

スコアやランク、 選択による結果の違いなど、 再挑戦したくなる仕組みを入れます。

📱

気軽に遊べる

PCでもスマホでも。 インストールせず、 ブラウザからすぐ遊べるゲームにします。

KEEP MAKING
